# สามก๊ก กลยุทธ์ Online (三国杀 · War of the Three Kingdoms)

เกมการ์ดซ่อนบทบาท "สามก๊ก กลยุทธ์" เล่นออนไลน์ผ่านเบราว์เซอร์ รองรับมือถือ มีระบบห้อง บอท และกลับเข้าเกมได้เมื่อหลุด

## เริ่มใช้งาน

```bash
npm install
npm start            # http://localhost:3000
```

ตัวแปรสภาพแวดล้อม: `PORT` (ค่าเริ่มต้น 3000), `BOT_DELAY` (ms ระหว่างการตัดสินใจของบอท ค่าเริ่มต้น 900)

ทดสอบ: `npm test`

## 🖼 ภาพประกอบ (สร้างจากโค้ด บันทึกถาวร)

ภาพทุกใบ — ตัวละคร 25 ตัว, การ์ด 32 ชนิด, หลังไพ่ และผ้าปูโต๊ะ — **วาดจากโค้ดทีละพิกเซล (RGB)** แบบ pixel art
ด้วยตัวสร้างภาพใน `public/artgen/` (ไม่ใช้ AI และไม่ใช้ภาพจากที่อื่น) แล้วบันทึกถาวรเป็นไฟล์ PNG ใน `public/art/`
พร้อม `manifest.json` ที่เก็บลายนิ้วมือ SHA-256 ของทุกไฟล์

- ดูภาพพร้อมข้อมูลการ์ดได้ที่ `/gallery.html` (ติ๊ก "วาดใหม่สด" เพื่อให้เบราว์เซอร์วาดใหม่จากโค้ดแล้วเทียบกับไฟล์ทีละพิกเซล)
- ภาพเป็นไฟล์คงที่ ไม่มีหน้าแก้ไข/อัปโหลด และเซิร์ฟเวอร์ไม่มี API สำหรับเขียนไฟล์
- `npm test` ตรวจว่าไฟล์ทุกไฟล์ตรงกับที่ตัวสร้างภาพวาดทุกพิกเซล — ถ้ามีใครแก้หรือเปลี่ยนไฟล์ การทดสอบจะไม่ผ่าน
- ผู้ดูแลที่ต้องการเปลี่ยนภาพ: แก้ `public/artgen/designs.js` แล้วรัน `npm run build:art` และ commit (ตรวจอย่างเดียว: `npm run build:art -- --check`)

## ฟีเจอร์

- **ระบบห้อง**: สร้างห้องได้รหัส 4 ตัว ส่งลิงก์ `?room=CODE` ให้เพื่อน หัวห้องเพิ่ม/เตะบอทและเริ่มเกมได้ ผู้เล่น 2–10 คน
- **กลับเข้าเกม (rejoin)**: เบราว์เซอร์เก็บ token ไว้ใน localStorage ปิดแท็บ/รีเฟรช/เน็ตหลุด แล้วเปิดใหม่ระบบจะพากลับที่นั่งเดิมพร้อมคำสั่งที่รออยู่
  - ระหว่างหลุด ถ้าถึงตาคุณ ระบบรอ ~12 วินาทีแล้วให้บอทตัดสินใจแทนชั่วคราว (ช่วงเล่นการ์ดจะจบเทิร์นให้)
  - กด "ออก" ระหว่างเกม = ยกที่นั่งให้บอทเล่นแทนถาวร
- **บทบาท**: จักรพรรดิ / ขุนนางภักดี / กบฏ / ผู้ทรยศ ตามจำนวนผู้เล่นมาตรฐาน
- **การ์ด 108 ใบ**: พื้นฐาน, กลยุทธ์ (รวม ไร้ช่องโหว่ แบบโต้กลับกันได้), กลยุทธ์หน่วงเวลา, อาวุธ 9 ชนิด, เกราะ, ม้า
- **ตัวละคร 25 ตัว** (ชุดมาตรฐาน จ๊ก/วุย/ง่อ/อิสระ) พร้อมทักษะทั้งหมด รวมทักษะจักรพรรดิ
- **บอท** เล่นตามบทบาทโดยเดาฝ่ายจากพฤติกรรม ใช้เติมห้องหรือเล่นแทนคนที่ออก
- **บอทพูดคุยและหลอกกัน** (`server/game/banter.js`): เกือบ 300 ประโยคตามสถานการณ์ กบฏ/ผู้ทรยศแกล้งทำเป็นภักดีจนกว่าจะเผยตัว กล่าวหากัน ขอลูกท้อ ขอบคุณ ฯลฯ แสดงเป็นลูกโป่งคำพูดบนโต๊ะ และตอบเมื่อถูกเอ่ยชื่อในแชท
- แชทในห้อง, บันทึกเหตุการณ์, ตัวจับเวลา

## โครงสร้าง

```
server/
  index.js        HTTP + Socket.IO
  rooms.js        ระบบห้อง, token/rejoin, broadcast สถานะรายคน
  game/
    engine.js     กฎเกม (async state machine — ทุกการตัดสินใจคือ prompt ที่ await)
    cards.js      ข้อมูลการ์ด
    heroes.js     ตัวละคร / ทักษะ / บทบาท
    bot.js        AI บอท
public/           ไคลเอนต์ (HTML/CSS/JS ล้วน ไม่ต้อง build)
  gallery.html    คลังภาพ + ฐานข้อมูลการ์ด (อ่านอย่างเดียว)
  artgen/         ตัวสร้างภาพ pixel art (raster.js, designs.js) ใช้ได้ทั้ง Node และเบราว์เซอร์
  art/            ภาพที่สร้างแล้ว (PNG) + manifest.json — ห้ามแก้ด้วยมือ
scripts/
  build-art.js    สร้าง/ตรวจสอบภาพทั้งหมด
  png.js          ตัวเข้ารหัส PNG
test/             ทดสอบ engine (จำลองเกมบอทหลายร้อยเกม) และ end-to-end ผ่าน socket
```

เซิร์ฟเวอร์เป็นผู้ตัดสินทั้งหมด (authoritative) ไคลเอนต์ได้รับเฉพาะข้อมูลที่ตัวเองควรเห็น (มือของผู้อื่นและบทบาทลับไม่ถูกส่ง)
สถานะเกมเก็บในหน่วยความจำ — ถ้ารีสตาร์ทเซิร์ฟเวอร์ ห้องที่เล่นอยู่จะหายไป
